🌙 LUNAR — Superhero Help Portal

The Empath. The Healer. The Guardian of the Night.



"She doesn't fight for glory. She fights so others don't have to suffer alone."

A modern, interactive superhero help portal featuring an original character Lunar. Visitors can share their problems through a conversational chatbot, and their request is automatically emailed for help.



✨ Features





Immersive intro animation based on Lunar’s origin story



Beautiful, responsive superhero-themed website



Conversational chatbot that feels like talking to Lunar



Step-by-step data collection (Name → Age → Location → Email → Problem)



Automatic email notification when someone needs help



Fully responsive (mobile + desktop)



🦸 About Lunar

Lunar is an original superhero who can feel the emotions and pain of others. Under the moonlight her powers grow stronger. She doesn’t fight for glory — she fights so no one has to suffer alone.





Personality: Calm, empathetic, protective, gentle yet strong



Powers: Emotional sensing, healing through moonlight, protective aura



Mission: Help people carry their invisible burdens



🛠️ Tech Stack





Frontend: Next.js + Tailwind CSS + Framer Motion



Chatbot: Custom conversational UI



Email: EmailJS



Hosting: Vercel



🚀 Getting Started

Prerequisites





Node.js (v18 or higher)



npm or yarn

Installation

# Clone the repository
git clone https://github.com/semantris/lunar-help-portal.git

# Go into the project folder
cd lunar-help-portal

# Install dependencies
npm install

# Run the development server
npm run dev

Open http://localhost:3000 in your browser.
